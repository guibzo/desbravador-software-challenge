Estou te enviando o desafio técnico para a vaga de Front-End da Desbravador Software.
📌 Objetivo do desafio:
Desenvolver uma aplicação client-side que consuma a API do GitHub e exiba os repositórios mais populares de um usuário.

https://github.com/DesbravadorSoftware/desafioFront

🔧 Principais requisitos técnicos:
Não utilizar frameworks como Vue, Angular, etc. (React é permitido, mas não obrigatório)
Uso obrigatório de rotas
Pode utilizar Fetch API, jQuery ou Axios (preferência por Axios)
Layout responsivo seguindo padrões do Bootstrap

📋 Regras de negócio:
Buscar um usuário do GitHub
Exibir detalhes do usuário (avatar, bio, seguidores, etc.)
Listar repositórios ordenados por estrelas (decrescente)
Permitir alteração da ordenação
Tela de detalhes do repositório (com link para o GitHub)

📦 Entrega:
Projeto no GitHub
README com instruções de instalação e execução
Link da aplicação publicada (diferencial)

📝 Critérios de avaliação:
Organização do projeto
Boas práticas de desenvolvimento
Atendimento aos requisitos
Uso de tecnologias atuais

Reforçamos que o teste é individual e autoral.
Não é permitido utilizar Inteligência Artificial, como ChatGPT, Copilot ou ferramentas similares, para desenvolver a solução. Também não é permitido copiar soluções prontas da internet.
Durante a análise do código, iremos avaliar a senioridade técnica do candidato com base na qualidade da implementação entregue. Por isso, a organização, clareza, arquitetura, decisões técnicas e qualidade do código serão fundamentais para a avaliação.
Caso seja identificado uso de IA, plágio ou descumprimento das instruções, o candidato será desclassificado do processo.
